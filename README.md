
# Console-Based Expense Tracker Application

## Project Overview
The Expense Tracker is a console-based application
developed using Core Java. It helps users manage
their daily expenses and maintain expense records.

## Technologies Used
- Java
- OOP Concepts
- ArrayList
- File Handling
- Exception Handling
- LocalDate
- BigDecimal

## Features
1. Add Expenses
2. View Expenses
3. Update Expenses
4. Delete Expenses
5. Calculate Total Expenses
6. Category-wise Expense Summary
7. Store records using CSV file handling

## How to Run

1. Install JDK 8 or above.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

   javac src/ExpenseTracker.java

5. Run the application:

   java -cp src ExpenseTracker

## Data Storage
Expense records are stored in expenses.csv
and loaded when the application starts.
